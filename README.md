# Globus Travel Manager

Система управления туристическим агентством "Глобус".

## Функционал

### Роли пользователей:
1. **Гость** - просмотр доступных туров
2. **Клиент** - просмотр туров и оформление заявок
3. **Менеджер** - полное управление турами, заявками, автобусами
4. **Администратор** - управление клиентами и расширенные функции

### Основные возможности:
- 📊 Управление турами (CRUD, фильтрация, сортировка, поиск)
- 📋 Управление заявками (подтверждение, отмена, создание)
- 🚌 Управление типами автобусов
- 👥 Управление клиентами
- 📈 Статистика и отчеты
- 🔐 Авторизация и ролевой доступ

## Установка и запуск

### Требования:
- .NET Framework 4.7.2+
- SQL Server
- Visual Studio 2019+

### Шаги установки:
1. Клонировать репозиторий
2. Выполнить скрипт `Database/CreateDatabase.sql` в SSMS
3. Открыть решение в Visual Studio
4. Запустить приложение (F5)
